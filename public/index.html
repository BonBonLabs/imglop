How to make a QR code that actually scans when printed

By BonBon Labs · Updated October 13, 2026

A QR code is only useful if it scans. This guide covers the colors, error correction, size and blank border that make a printed code work every time, and how to test it before you spend money on printing.

Why some printed QR codes fail

A QR code that looks fine on screen can fail on paper. Almost every failure comes from one of five things: low contrast, inverted colors, too small a print, no blank border, or a code packed with too much text. The good news is that each one is easy to avoid.

Step by step

  1. Open the QR tool.Go to imgLop's Quick Utilities and choose the QR code maker. It is free and needs no account.
  2. Enter a short link.Type the web address or text into Text or URL. Shorter content makes a simpler code with bigger squares, which scans more easily. If your link is long, use a short link or a short page address on your own site.
  3. Use dark on light.Keep the Foreground dark (black or a deep color) and the Background light (white). The presets Classic, Crimson, Indigo and Midnight are all dark-on-light and safe. Avoid light-on-dark colors, since many scanners struggle with them.
  4. Choose the error correction.Medium 15% is a good default. Pick Quartile 25% or High 30% if the code will get scuffed, folded or printed on a rough surface, or if you plan to put a logo over the middle. Higher levels add more squares, so the code gets denser.
  5. Download at a large size.Choose a Download size of 2048 or 4096 px for print, so it stays sharp when enlarged. For a small web image, 512 or 1024 px is enough.
  6. Keep the quiet zone.The Quiet-zone margin is the blank border around the code. Leave it on. Scanners use it to find where the code starts, so never crop it off or let other artwork run into it.
  7. Click Download PNG and place it in your design.

How big should a printed QR code be?

A common rule is that the code should be about one-tenth of the scanning distance. A code on a flyer held at arm's length can be about 2 cm (0.8 in) wide as a minimum, but bigger is safer. For a poster scanned from two meters away, aim for around 20 cm (8 in). When in doubt, go larger than you think you need. Do not stretch the code unevenly, and keep it square.

Where it is printedSuggested minimum width
Business card2 cm (0.8 in)
Flyer, menu or table tent3 to 4 cm (1.2 to 1.6 in)
Poster or shop window10 cm (4 in) or more, larger for long distances

Test before you print 500 copies

  1. Print one copy at the real size on the real paper.
  2. Scan it with at least two different phones, with the camera app, in normal indoor light.
  3. Scan it from the distance a customer will use.
  4. Confirm the link opens the right page on mobile data, not just Wi-Fi.
  5. Only then print the full run.

Link tip: A QR code points to a fixed address. If that page moves or the link breaks, every printed copy breaks too. Use a stable address you control, and double-check spelling before printing.

Common mistakes

  • Light code on a dark background. Use a dark code on a light background.
  • Low-contrast brand colors. Pastel on white looks lovely and scans badly. If your brand color is light, use a darker shade for the code.
  • Gloss glare. Shiny laminate can reflect light. Matte stock scans more reliably.
  • Logo too big. If you add a logo, keep it small in the middle and raise the error correction level.
  • Too much text. Link to a page instead of putting a paragraph inside the code.

Privacy: The QR code is created in your browser. The text or link you enter is not sent to or stored on a server.

Questions people ask

Do QR codes made with imgLop expire?

No. The code is a plain image of the text you entered, so it has no expiry date and needs no account. It works as long as the page it links to stays online.

Is there a scan limit or a fee?

No. The QR maker is free and has no scan counts, because the code does not go through any service.

What size should I download for printing?

Use 2048 or 4096 px so the code stays sharp when it is printed large. Then size it in your design or print program.

Which error correction level should I choose?

Medium 15% suits most printing. Use Quartile 25% or High 30% if the code may get damaged or if you place a logo in the middle.

Can I change the colors?

Yes, but keep a dark code on a light background with strong contrast. The Classic, Crimson, Indigo and Midnight presets are all safe choices.

How to make a Wi-Fi QR code

By BonBon Labs · Updated October 14, 2026

Stop reading out your Wi-Fi password. Make a QR code that guests scan with their camera to join your network, free and private, and learn how to share it safely.

Make your Wi-Fi codeFree, unlimited, and private.
Open the Wi-Fi QR maker

Why a Wi-Fi QR code is handy

A Wi-Fi QR code lets a guest point their phone camera at a card and join your network, with no spelling out a long password. It suits a home, a rental, a cafe, a waiting room or an office. You make the code once and print it, or show it on a screen.

Step by step

  1. Open the QR tool.Go to imgLop's Wi-Fi QR maker. It is in Quick Utilities and needs no account. The menu What is the code for? is already set to Wi-Fi network.
  2. Type the network name.Enter it exactly as it appears on your phone's Wi-Fi list, including capital letters, in Network name (SSID).
  3. Type the password.Enter it exactly as it is, including capitals. If your password is shorter than 8 characters, the tool warns you, since modern Wi-Fi security (WPA) needs at least 8.
  4. Check the security type.Leave Security on WPA / WPA2 / WPA3 for most routers made in the last ten years. Choose WEP only for very old routers, and No password for an open network. If your network name is hidden, tick Hidden network.
  5. Choose the look.Use a dark code on a light background, as in our printing guide. Pick a large Download size such as 2048 px if you will print it.
  6. Click Download PNG, print it or put it in a frame, then test it.

Test it before you share it

  1. Use a phone that has never joined your network, or turn Wi-Fi off and on again on yours.
  2. Open the camera and point it at the code. On most current iPhones and Android phones, a prompt to join the network appears.
  3. Tap it and check that the phone connects and loads a web page.
  4. If it fails, check the name and password for capital letters and spelling, then try again.
  5. If a phone does not show the join prompt, it may be an older model or camera. Have the person choose the network in their Wi-Fi settings and type the password instead.

Safety: A Wi-Fi QR code contains your password, and anyone who scans or photographs it can use it. Do not post it online. For guests, a separate guest network, if your router has one, keeps your own devices apart. If you change your password, make and print a new code.

Tips

  • Put it where guests will see it. A small frame near the entrance, the fridge or the reception desk works well. A short line such as "Scan to join Wi-Fi" helps people who have not seen one before.
  • Keep a written copy. Some older phones and laptops cannot scan a code. Print the network name and password beside it.
  • Use a matte print. Glare from glossy paper or glass can stop a camera reading the code.

Privacy: The code is made in your browser. Your network name and password are not sent to a server or saved by imgLop. They are only inside the picture you download.

Questions people ask

Will it work on iPhone and Android?

Yes, on most current phones. Open the camera app and point it at the code. A prompt to join the network should appear.

Is my Wi-Fi password sent anywhere?

No. The code is made in your browser. The password is only inside the QR image you download, so keep that image private.

Does the code expire?

No. It works until you change the network name or password. After that, make a new code.

What if my network is hidden?

Tick Hidden network before you download the code.

Can it handle special characters in the password?

Yes. Characters that need special handling inside a Wi-Fi code are handled for you. Type the password exactly as it is.
